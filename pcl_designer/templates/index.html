Design matrix

Default view is the Run Sheet: one column per factor, showing the level to set in each run. This is what you need to actually run the experiment. Toggle below to also show interaction columns (the expanded model matrix, ready to use as the X matrix when fitting a model later).

Note on the criterion value: the D-criterion above is computed under the evaluator you selected (PCL surrogate, exact GLMM, or independence GLM). When the evaluator is the PCL surrogate, the number is the log-determinant of the surrogate information matrix — an approximation of the exact-GLMM D-criterion. The two agree closely in the paper's operating regime but are formally distinct quantities.
